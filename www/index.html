Server Features

Everything an HTTP server needs

A complete request lifecycle — parsed, validated, routed and answered — implemented by hand.

⇄

HTTP Methods

Full GET, POST and DELETE handling with correct status codes and headers.

≡

Static File Serving

Reads files from configured roots with automatic MIME-type and Content-Length.

☰

Directory & Autoindex

Resolves index files, or generates a clean directory listing when enabled.

⚠

Custom Error Pages

Configurable error pages per status code, with elegant built-in fallbacks.

λ

CGI Execution

Runs CGI scripts (e.g. Python) per location, streaming their output back.

∞

Non-blocking I/O

A single poll() event loop multiplexes every client without threads.
